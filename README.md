# Happyness

Happyness - это современная система управления проектами и подрядчиками, разработанная для эффективного взаимодействия между клиентами и исполнителями.

## Функциональные возможности

- **Управление пользователями**: регистрация, аутентификация, управление профилями
- **Управление проектами**: создание, редактирование, удаление проектов
- **Управление подрядчиками**: поиск, оценка, найм подрядчиков
- **Управление запросами**: создание запросов на выполнение работ
- **Коммуникация**: встроенная система обмена сообщениями
- **Отчетность**: генерация отчетов о выполненных работах

## Установка и запуск

### Предварительные требования

- Node.js 18+
- Docker и Docker Compose
- Git

### Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/yourusername/happyness.git
   cd happyness
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте файл .env на основе .env.example:

   ```bash
   cp .env.example .env
   ```

4. Запустите базы данных с помощью Docker Compose:

   ```bash
   docker-compose up -d
   ```

5. Примените миграции базы данных:
   ```bash
   npx prisma migrate deploy
   ```

### Запуск

#### Режим разработки

```bash
npm run dev
```

#### Режим production

```bash
npm run build
npm start
```

## Архитектура проекта

Проект разделен на две основные части:

- **Frontend**: Next.js приложение с App Router
- **Backend**: NestJS API с модульной архитектурой

### Backend API

Backend API построен с использованием NestJS и предоставляет следующие возможности:

- **Модульная архитектура**: Система динамической загрузки модулей с управлением зависимостями
- **RESTful API**: Полноценное REST API для всех основных сущностей системы
- **Аутентификация и авторизация**: JWT-аутентификация с ролевой моделью доступа
- **Документация API**: Автоматическая генерация документации с использованием Swagger/OpenAPI

#### Основные эндпоинты API:

- `/api/v1/auth` - Аутентификация и управление пользователями
- `/api/v1/projects` - Управление проектами
- `/api/v1/contractors` - Управление подрядчиками
- `/api/v1/requests` - Управление запросами

#### Документация API

Документация API доступна по адресу `/api/docs` при запуске приложения в режиме разработки.
Она содержит полное описание всех эндпоинтов, параметров запросов и ответов.

### Frontend

Frontend построен с использованием Next.js и App Router, и включает:

- **Маршрутизация**: Современная маршрутизация на основе файловой системы
- **UI-компоненты**: Набор переиспользуемых компонентов с использованием shadcn/ui
- **Интеграция с API**: Типизированные клиенты для взаимодействия с backend API

## Разработка

### Запуск проекта

Для запуска проекта в режиме разработки:

```bash
# Запуск с использованием Docker
docker-compose up

# Или запуск отдельных компонентов
# Frontend
cd src/frontend
npm run dev

# Backend
cd src/backend
npm run start:dev
```

### API и документация

После запуска проекта документация API доступна по адресу:

```
http://localhost:4000/api/docs
```

Здесь вы можете изучить все доступные эндпоинты, их параметры и попробовать выполнить запросы.

### Стиль кода

Проект использует ESLint и Prettier для обеспечения единообразия стиля кода. Запустите линтеры перед коммитом:

```bash
npm run lint
```

### Тестирование

```bash
# Запуск тестов бэкенда
npm run test:backend

# Запуск тестов фронтенда
npm run test:frontend

# Запуск e2e-тестов
npm run test:e2e

# Запуск всех тестов
npm run test
```
