# Happyness

Happyness - это современная система управления проектами и подрядчиками, разработанная для эффективного взаимодействия между клиентами и исполнителями.

## Функциональные возможности

- **Управление пользователями**: регистрация, аутентификация, управление профилями
- **Управление проектами**: создание, редактирование, удаление проектов
- **Управление подрядчиками**: поиск, оценка, найм подрядчиков
- **Управление запросами**: создание запросов на выполнение работ
- **Коммуникация**: встроенная система обмена сообщениями
- **Отчетность**: генерация отчетов о выполненных работах

## Установка и запуск

### Предварительные требования

- Node.js 18+
- Docker и Docker Compose
- Git

### Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/yourusername/happyness.git
   cd happyness
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте файл .env на основе .env.example:

   ```bash
   cp .env.example .env
   ```

4. Запустите базы данных с помощью Docker Compose:

   ```bash
   docker-compose up -d
   ```

5. Примените миграции базы данных:
   ```bash
   npx prisma migrate deploy
   ```

### Запуск

#### Режим разработки

```bash
npm run dev
```

#### Режим production

```bash
npm run build
npm start
```

## Архитектура проекта

Проект разделен на две основные части:

- **Frontend**: Next.js приложение с App Router
- **Backend**: NestJS API с модульной архитектурой

### Backend API

Backend API построен с использованием NestJS и предоставляет следующие возможности:

- **Модульная архитектура**: Система динамической загрузки модулей с управлением зависимостями
- **RESTful API**: Полноценное REST API для всех основных сущностей системы
- **Аутентификация и авторизация**: JWT-аутентификация с ролевой моделью доступа
- **Документация API**: Автоматическая генерация документации с использованием Swagger/OpenAPI

#### Основные эндпоинты API:

- `/api/v1/auth` - Аутентификация и управление пользователями
- `/api/v1/projects` - Управление проектами
- `/api/v1/contractors` - Управление подрядчиками
- `/api/v1/requests` - Управление запросами

#### Документация API

Документация API доступна по адресу `/api/docs` при запуске приложения в режиме разработки.
Она содержит полное описание всех эндпоинтов, параметров запросов и ответов.

### Frontend

Frontend построен с использованием Next.js и App Router, и включает:

- **Маршрутизация**: Современная маршрутизация на основе файловой системы
- **UI-компоненты**: Набор переиспользуемых компонентов с использованием shadcn/ui
- **Интеграция с API**: Типизированные клиенты для взаимодействия с backend API

## Разработка

### Настройка окружения разработки

#### Требования

- Node.js 20.x или выше
- Docker и Docker Compose
- Git
- Опционально: OpenSSL (для генерации SSL сертификатов)

#### Первоначальная настройка

1. Клонируйте репозиторий:

   ```bash
   git clone <repository-url>
   cd happyness
   ```

2. Создайте .env файл из примера .env.example:

   ```bash
   cp .env.example .env
   ```

3. Установите зависимости:

   ```bash
   npm ci
   ```

4. Генерация сертификатов для HTTPS (опционально):

   - Linux/macOS:
     ```bash
     cd docker/nginx/ssl
     ./generate-certs.sh
     ```
   - Windows:
     ```powershell
     cd docker/nginx/ssl
     ./generate-certs.ps1
     ```

5. Запустите проект в режиме разработки:
   ```bash
   npm run docker:dev:build
   ```

### Скрипты для разработки

| Команда                     | Описание                                |
| --------------------------- | --------------------------------------- |
| `npm run dev`               | Запуск frontend и backend локально      |
| `npm run docker:dev`        | Запуск в Docker для разработки          |
| `npm run docker:dev:build`  | Сборка и запуск в Docker для разработки |
| `npm run docker:dev:down`   | Остановка контейнеров разработки        |
| `npm run docker:prod`       | Запуск в Docker для продакшна           |
| `npm run docker:prod:build` | Сборка и запуск в Docker для продакшна  |
| `npm run docker:prod:down`  | Остановка продакшн контейнеров          |

### Работа с базой данных

Для удобной работы с базой данных используйте следующие скрипты:

- Linux/macOS:

  ```bash
  # Создание резервной копии
  ./scripts/db-utils.sh backup

  # Восстановление из резервной копии
  ./scripts/db-utils.sh restore <путь-к-файлу>

  # Сброс базы данных
  ./scripts/db-utils.sh reset
  ```

- Windows:

  ```powershell
  # Создание резервной копии
  ./scripts/db-utils.ps1 backup

  # Восстановление из резервной копии
  ./scripts/db-utils.ps1 restore <путь-к-файлу>

  # Сброс базы данных
  ./scripts/db-utils.ps1 reset
  ```

### Отладка приложения

Проект настроен для отладки как Frontend, так и Backend частей:

1. Откройте проект в VS Code
2. Перейдите в раздел "Run and Debug" (Ctrl+Shift+D)
3. Выберите конфигурацию:

- "Frontend: Next.js" - для отладки frontend
- "Backend: NestJS" - для отладки backend

4. Нажмите F5 для начала отладки
