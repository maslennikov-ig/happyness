# Changelog

Все значимые изменения в проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Добавлено

- Создана базовая структура проекта
- Настроен Next.js для фронтенда с использованием App Router
- Настроен NestJS для бэкенда
- Настроена интеграция с Prisma ORM
- Добавлена базовая схема базы данных
- Настроена аутентификация с использованием JWT
- Добавлены базовые страницы и компоненты для фронтенда
- Добавлены модули для бэкенда (auth, users, projects, requests, contractors)
- Настроены Docker контейнеры для PostgreSQL и Redis
- Настроены тесты с использованием Vitest
- Определены API-контракты системы, включая:
  - Стратегия версионирования API (URL-версионирование)
  - Структура эндпоинтов для ключевых сущностей (users, contractors, projects, requests, auth)
  - Стандарты именования эндпоинтов (RESTful подход)
  - Форматы ответов API и обработка ошибок (единые структуры для успешных ответов и ошибок)
  - Коды ошибок и их описания (категоризированные по типам)
  - Примеры реализации API для основных сущностей
  - Интеграция API-контрактов с другими компонентами проекта
  - Правила для Cursor IDE (.cursor/rules/api_contracts.mdc)
- Обновлена документация проекта:
  - Добавлены документы по API-контрактам в docs/tasks/tasks1/
  - Обновлены README.md в корне проекта и в директории docs/
- Реализация API-контрактов в коде для модулей:
  - users
  - contractors
  - projects
  - requests
- Интеграция с фронтендом
- Автоматические тесты API
- Инициализирован базовый проект Next.js с App Router
- Инициализирован базовый проект NestJS
- Настроена базовая маршрутизация через App Router
- Настроена модульная структура бэкенд-приложения
- Настроена конфигурация с поддержкой переменных окружения
- Создан файл .env.example с примерами переменных окружения
- Настроена конфигурация сборки и оптимизации
- Улучшенный PrismaService с поддержкой транзакций и обработкой ошибок
- Модульная система с базовым интерфейсом IModule
- Абстрактный класс BaseModule для упрощения создания новых модулей
- ModuleRegistry для управления жизненным циклом модулей и их зависимостями
- Глобальный CoreModule для предоставления основных сервисов приложения
- Настроены базовые UI-компоненты с использованием shadcn/ui:
  - Button - кнопки с различными вариантами и размерами
  - Card - карточки с заголовком, содержимым и футером
  - Dialog - модальные диалоги
  - Input - поля ввода
  - Label - метки для форм
  - Select - выпадающие списки
  - Toast - всплывающие уведомления
  - Tooltip - всплывающие подсказки
  - Toaster - система управления уведомлениями
- Настроены стили и темы с использованием Tailwind CSS
- Добавлена поддержка анимаций для компонентов
- Создана демо-страница UI-компонентов для демонстрации и тестирования

### Изменено

- Улучшена структура документации
- Обновлены инструкции по установке и запуску
- Обновлена конфигурация Tailwind CSS для поддержки компонентов shadcn/ui
- Добавлена поддержка CSS-переменных для темизации

### Исправлено

- Исправлены ошибки в конфигурации ESLint
- Исправлены ошибки в схеме базы данных
