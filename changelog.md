## [0.3.0] - 2024-05-18 - Улучшение базовых моделей данных

### Добавлено

- Расширена схема базы данных Prisma с новыми сущностями:
  - Proposal - предложения подрядчиков
  - Milestone - вехи проектов
  - Task - задачи
  - Message - сообщения
  - Notification - уведомления
  - Document - документы
  - Attachment - вложения
  - Review - отзывы
  - PortfolioItem - элементы портфолио
  - PaymentMethod - методы оплаты
  - Transaction - транзакции
  - ActivityLog - журнал активности
  - Skill - навыки
  - Category - категории
- Добавлены расширенные атрибуты к существующим сущностям:
  - User: phone, avatar, isActive, lastLoginAt, deletedAt
  - Contractor: specializations, experience, reviewCount, contactEmail, contactPhone, website, address, socialLinks, availableHours, deletedAt
  - Project: completedAt, priority, tags, visibility, deletedAt
  - Request: category, specializationTags, requiredSkills, location, isRemote, isUrgent, deletedAt
- Добавлены новые перечисления (ENUM):
  - Priority - приоритеты (LOW, MEDIUM, HIGH, URGENT)
  - Visibility - видимость (PUBLIC, PRIVATE, INVITATION_ONLY)
  - ProposalStatus, MilestoneStatus, TaskStatus, NotificationType, PaymentType, TransactionType, TransactionStatus
- Расширены существующие перечисления:
  - ProjectStatus: добавлены значения ON_HOLD, REVIEW
  - RequestStatus: добавлены значения PENDING, REJECTED
- Добавлены индексы для оптимизации запросов в базе данных
- Реализована стратегия мягкого удаления (soft delete) через поле deletedAt
- Настроены правила каскадного удаления и обработки связей между сущностями
- Обновлены интерфейсы типов в соответствии с расширенной схемой
- Создана документация по моделям данных в docs/database/models/
- Добавлена диаграмма базы данных в формате Mermaid
- Разработан слой репозиториев для абстракции доступа к данным:
  - Создан абстрактный базовый репозиторий (BaseRepository)
  - Реализованы репозитории для основных сущностей (User, Project, Contractor, Request)
  - Добавлены методы для сложных запросов с фильтрацией и пагинацией
  - Реализована поддержка транзакций в репозиториях
  - Добавлена обработка ошибок и логирование в репозиториях
  - Реализованы методы для мягкого удаления и восстановления записей
  - Добавлены специализированные методы поиска для каждой сущности
  - Реализована возможность получения связанных данных через include

### Изменено

- Полностью обновлен файл schema.prisma с расширенной схемой
- Обновлен файл src/backend/types/index.ts с полным набором интерфейсов и типов
- Создана новая миграция Prisma (20250518054114_extended_schema)
