# Архитектура системы Happyness

## Обзор архитектуры

Данный документ содержит ссылки на все архитектурные документы системы Happyness, разработанные в рамках задачи 2.1.

## Основные архитектурные документы

1. **[Результаты проектирования архитектуры](tasks/tasks1/task21_result.md)** - обзор выполненной работы по проектированию архитектуры

2. **[Анализ компонентов системы](tasks/tasks1/task21_components.md)** - детальный анализ всех компонентов системы, включая ядро и функциональные модули

3. **[Взаимодействие компонентов системы](tasks/tasks1/task21_interactions.md)** - описание взаимодействия между компонентами системы, включая диаграмму взаимодействия

4. **[Архитектурные диаграммы (модель C4)](tasks/tasks1/task21_c4_diagrams.md)** - набор архитектурных диаграмм разного уровня абстракции

5. **[Модульная архитектура системы](tasks/tasks1/task21_modular_architecture.md)** - детальное описание модульной архитектуры системы

6. **[Рекомендации по структуре проекта](tasks/tasks1/task21_project_structure.md)** - рекомендации по организации файлов и каталогов проекта

## Ключевые архитектурные решения

- Модульная архитектура с четким разделением на ядро и функциональные модули
- Разделение на серверную (NestJS) и клиентскую (Next.js) части
- Слабая связанность компонентов через четко определенные интерфейсы
- Асинхронное взаимодействие через систему событий
- Масштабируемая структура базы данных (Prisma + PostgreSQL)

## Технологический стек

### Серверная часть:
- NestJS
- TypeScript
- Prisma
- PostgreSQL
- Redis

### Клиентская часть:
- Next.js
- TypeScript
- React
- TailwindCSS

## Как использовать эту документацию

- При разработке новых модулей следуйте принципам, описанным в [модульной архитектуре](tasks/tasks1/task21_modular_architecture.md)
- При создании новых файлов и каталогов придерживайтесь [рекомендаций по структуре проекта](tasks/tasks1/task21_project_structure.md)
- При проектировании взаимодействия между компонентами используйте подходы из [документа по взаимодействию](tasks/tasks1/task21_interactions.md)
- При обновлении архитектуры обновляйте соответствующие документы и диаграммы
