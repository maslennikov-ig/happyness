# Документация по базе данных Happyness

В этой директории содержится документация по базе данных проекта Happyness, включая схему базы данных, миграции, модели данных и диаграммы.

## Структура документации по базе данных

- [**models/**](./models/) - Документация по моделям данных

  - [README.md](./models/README.md) - Обзор моделей данных
  - [diagram.md](./models/diagram.md) - Диаграмма ER в формате Mermaid

- [**migrations/**](./migrations/) - Информация о миграциях базы данных (появится позже)

## Навигация

- [Обзор моделей данных](./models/README.md) - Подробное описание всех сущностей, их атрибутов и связей
- [Диаграмма базы данных](./models/diagram.md) - Визуальное представление структуры базы данных
- [Версии схемы](./migrations/) - История изменений схемы базы данных

## Связь с Prisma

Модели данных, описанные в этой документации, реализованы с использованием Prisma ORM и находятся в файле:

- [prisma/schema.prisma](../../prisma/schema.prisma)

## Обновление документации по базе данных

При изменении схемы базы данных необходимо:

1. Создать и применить миграцию Prisma
2. Обновить соответствующие документы в директории docs/database/
3. Обновить диаграмму ER в файле docs/database/models/diagram.md
4. Добавить информацию о миграции в docs/database/migrations/ (если применимо)
5. Обновить changelog.md в корне проекта
