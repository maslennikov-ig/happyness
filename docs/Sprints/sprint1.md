- **Риск:** Сложность интеграции модульной архитектуры с NestJS  
  **Стратегия минимизации:** Изучить документацию NestJS по динамическим модулям и провести spike-исследование до начала реализации

- **Риск:** Проблемы с производительностью в Docker на локальной разработке  
  **Стратегия минимизации:** Оптимизировать конфигурацию Docker (volumes, restart policies), использовать легковесные версии образов
