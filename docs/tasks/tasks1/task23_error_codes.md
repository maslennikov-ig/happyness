# Справочник кодов ошибок API

В данном документе представлен полный справочник кодов ошибок, которые могут возникать при работе с API системы Happyness. Каждый код ошибки сопровождается описанием, возможными причинами возникновения и рекомендациями по устранению.

## Структура ответа с ошибкой

Все ошибки API возвращаются в едином формате:

```json
{
  "status": "error",
  "error": {
    "code": "ERROR_CODE",
    "message": "Описание ошибки",
    "details": "Дополнительная информация об ошибке (опционально)",
    "timestamp": "2025-01-20T15:45:00Z",
    "path": "/v1/resource/123",
    "requestId": "req-abc123",
    "validationErrors": [] // только для ошибок валидации
  }
}
```

## Категории ошибок

Коды ошибок сгруппированы по категориям для удобства использования и обработки.

## 1. Общие ошибки (1000-1999)

### 1000 - INTERNAL_SERVER_ERROR

- **HTTP-код**: 500
- **Описание**: Внутренняя ошибка сервера
- **Возможные причины**: Непредвиденная ошибка на сервере
- **Рекомендации**: Повторите запрос позже. Если проблема сохраняется, обратитесь в службу поддержки с указанием requestId.

### 1001 - SERVICE_UNAVAILABLE

- **HTTP-код**: 503
- **Описание**: Сервис временно недоступен
- **Возможные причины**: Плановое обслуживание, перегрузка сервера, обновление системы
- **Рекомендации**: Повторите запрос через несколько минут.

### 1002 - INVALID_REQUEST

- **HTTP-код**: 400
- **Описание**: Некорректный запрос
- **Возможные причины**: Неверный формат запроса, отсутствие обязательных параметров
- **Рекомендации**: Проверьте формат и параметры запроса согласно документации API.

### 1003 - RATE_LIMIT_EXCEEDED

- **HTTP-код**: 429
- **Описание**: Превышен лимит запросов
- **Возможные причины**: Слишком много запросов за короткий промежуток времени
- **Рекомендации**: Уменьшите частоту запросов. Повторите попытку через время, указанное в заголовке `Retry-After`.

### 1004 - METHOD_NOT_ALLOWED

- **HTTP-код**: 405
- **Описание**: Метод не разрешен
- **Возможные причины**: Использование неподдерживаемого HTTP-метода для данного эндпоинта
- **Рекомендации**: Используйте правильный HTTP-метод согласно документации API.

### 1005 - UNSUPPORTED_MEDIA_TYPE

- **HTTP-код**: 415
- **Описание**: Неподдерживаемый тип медиа
- **Возможные причины**: Неверный Content-Type в запросе
- **Рекомендации**: Проверьте заголовок Content-Type. API поддерживает application/json.

## 2. Ошибки аутентификации и авторизации (2000-2999)

### 2000 - UNAUTHORIZED

- **HTTP-код**: 401
- **Описание**: Требуется аутентификация
- **Возможные причины**: Отсутствие токена авторизации, пользователь не вошел в систему
- **Рекомендации**: Выполните вход в систему и получите действительный токен авторизации.

### 2001 - INVALID_CREDENTIALS

- **HTTP-код**: 401
- **Описание**: Неверные учетные данные
- **Возможные причины**: Неправильный email или пароль
- **Рекомендации**: Проверьте правильность email и пароля. Воспользуйтесь функцией восстановления пароля при необходимости.

### 2002 - FORBIDDEN

- **HTTP-код**: 403
- **Описание**: Недостаточно прав для выполнения операции
- **Возможные причины**: Пользователь не имеет необходимых прав для доступа к ресурсу или выполнения операции
- **Рекомендации**: Запросите необходимые права у администратора или используйте другую учетную запись.

### 2003 - TOKEN_EXPIRED

- **HTTP-код**: 401
- **Описание**: Истек срок действия токена
- **Возможные причины**: Токен авторизации устарел
- **Рекомендации**: Используйте refresh-токен для получения нового токена доступа или выполните повторный вход.

### 2004 - INVALID_TOKEN

- **HTTP-код**: 401
- **Описание**: Недействительный токен
- **Возможные причины**: Токен поврежден, подделан или отозван
- **Рекомендации**: Выполните повторный вход для получения нового токена.

### 2005 - ACCOUNT_LOCKED

- **HTTP-код**: 403
- **Описание**: Учетная запись заблокирована
- **Возможные причины**: Слишком много неудачных попыток входа или блокировка администратором
- **Рекомендации**: Обратитесь в службу поддержки или дождитесь автоматической разблокировки.

### 2006 - ACCOUNT_INACTIVE

- **HTTP-код**: 403
- **Описание**: Учетная запись неактивна
- **Возможные причины**: Учетная запись не активирована или деактивирована
- **Рекомендации**: Проверьте электронную почту для активации аккаунта или обратитесь в службу поддержки.

## 3. Ошибки ресурсов (3000-3999)

### 3000 - RESOURCE_NOT_FOUND

- **HTTP-код**: 404
- **Описание**: Ресурс не найден
- **Возможные причины**: Ресурс с указанным идентификатором не существует или был удален
- **Рекомендации**: Проверьте правильность идентификатора ресурса.

### 3001 - RESOURCE_ALREADY_EXISTS

- **HTTP-код**: 409
- **Описание**: Ресурс уже существует
- **Возможные причины**: Попытка создать ресурс с уникальными параметрами, которые уже используются
- **Рекомендации**: Используйте другие параметры или обновите существующий ресурс.

### 3002 - RESOURCE_DELETED

- **HTTP-код**: 410
- **Описание**: Ресурс удален
- **Возможные причины**: Ресурс был удален и больше недоступен
- **Рекомендации**: Используйте другой ресурс или создайте новый.

### 3003 - RESOURCE_EXPIRED

- **HTTP-код**: 410
- **Описание**: Истек срок действия ресурса
- **Возможные причины**: Временный ресурс, срок действия которого истек
- **Рекомендации**: Создайте новый ресурс или обновите текущий.

### 3004 - RESOURCE_LOCKED

- **HTTP-код**: 423
- **Описание**: Ресурс заблокирован
- **Возможные причины**: Ресурс временно заблокирован для редактирования другим пользователем
- **Рекомендации**: Повторите попытку позже или свяжитесь с пользователем, блокирующим ресурс.

## 4. Ошибки валидации (4000-4999)

### 4000 - VALIDATION_ERROR

- **HTTP-код**: 422
- **Описание**: Ошибка валидации данных
- **Возможные причины**: Предоставленные данные не соответствуют требованиям
- **Рекомендации**: Проверьте данные согласно требованиям в поле validationErrors.

### 4001 - INVALID_PARAMETER

- **HTTP-код**: 400
- **Описание**: Некорректный параметр
- **Возможные причины**: Один или несколько параметров имеют неверный формат или значение
- **Рекомендации**: Проверьте параметры запроса согласно документации API.

### 4002 - MISSING_REQUIRED_FIELD

- **HTTP-код**: 400
- **Описание**: Отсутствует обязательное поле
- **Возможные причины**: В запросе отсутствует одно или несколько обязательных полей
- **Рекомендации**: Добавьте все обязательные поля в запрос.

### 4003 - INVALID_FORMAT

- **HTTP-код**: 400
- **Описание**: Некорректный формат данных
- **Возможные причины**: Данные не соответствуют ожидаемому формату (например, неверный формат даты, email)
- **Рекомендации**: Проверьте формат данных согласно документации API.

### 4004 - INVALID_ENUM_VALUE

- **HTTP-код**: 400
- **Описание**: Недопустимое значение перечисления
- **Возможные причины**: Значение не входит в список допустимых значений для поля
- **Рекомендации**: Используйте одно из допустимых значений, указанных в документации API.

### 4005 - STRING_TOO_SHORT

- **HTTP-код**: 400
- **Описание**: Строка слишком короткая
- **Возможные причины**: Длина строки меньше минимально допустимой
- **Рекомендации**: Увеличьте длину строки до минимально допустимой.

### 4006 - STRING_TOO_LONG

- **HTTP-код**: 400
- **Описание**: Строка слишком длинная
- **Возможные причины**: Длина строки превышает максимально допустимую
- **Рекомендации**: Сократите длину строки до максимально допустимой.

### 4007 - NUMBER_TOO_SMALL

- **HTTP-код**: 400
- **Описание**: Число слишком маленькое
- **Возможные причины**: Значение числа меньше минимально допустимого
- **Рекомендации**: Увеличьте значение числа до минимально допустимого.

### 4008 - NUMBER_TOO_LARGE

- **HTTP-код**: 400
- **Описание**: Число слишком большое
- **Возможные причины**: Значение числа превышает максимально допустимое
- **Рекомендации**: Уменьшите значение числа до максимально допустимого.

## 5. Ошибки бизнес-логики (5000-5999)

### 5000 - BUSINESS_RULE_VIOLATION

- **HTTP-код**: 422
- **Описание**: Нарушение бизнес-правила
- **Возможные причины**: Операция нарушает одно из бизнес-правил системы
- **Рекомендации**: Ознакомьтесь с деталями ошибки и бизнес-правилами системы.

### 5001 - INSUFFICIENT_FUNDS

- **HTTP-код**: 422
- **Описание**: Недостаточно средств
- **Возможные причины**: На счете недостаточно средств для выполнения операции
- **Рекомендации**: Пополните счет или измените сумму операции.

### 5002 - QUOTA_EXCEEDED

- **HTTP-код**: 422
- **Описание**: Превышена квота
- **Возможные причины**: Превышен лимит использования определенного ресурса или функции
- **Рекомендации**: Обновите тарифный план или дождитесь обновления квоты.

### 5003 - OPERATION_NOT_ALLOWED

- **HTTP-код**: 422
- **Описание**: Операция не разрешена
- **Возможные причины**: Текущее состояние ресурса не позволяет выполнить операцию
- **Рекомендации**: Проверьте требования к состоянию ресурса для выполнения операции.

### 5004 - DEPENDENCY_CONFLICT

- **HTTP-код**: 409
- **Описание**: Конфликт зависимостей
- **Возможные причины**: Операция нарушает зависимости между ресурсами
- **Рекомендации**: Разрешите конфликт зависимостей перед выполнением операции.

### 5005 - DUPLICATE_ENTRY

- **HTTP-код**: 409
- **Описание**: Дублирующаяся запись
- **Возможные причины**: Попытка создать запись, которая уже существует
- **Рекомендации**: Используйте уникальные значения или обновите существующую запись.

### 5006 - INVALID_STATE_TRANSITION

- **HTTP-код**: 422
- **Описание**: Недопустимый переход состояния
- **Возможные причины**: Попытка перевести ресурс в недопустимое состояние
- **Рекомендации**: Проверьте допустимые переходы состояний для данного ресурса.

### 5007 - DEADLINE_EXCEEDED

- **HTTP-код**: 422
- **Описание**: Превышен срок выполнения
- **Возможные причины**: Операция не может быть выполнена, так как превышен срок ее выполнения
- **Рекомендации**: Создайте новую операцию или обновите сроки.

## 6. Ошибки загрузки файлов (6000-6999)

### 6000 - FILE_TOO_LARGE

- **HTTP-код**: 413
- **Описание**: Файл слишком большой
- **Возможные причины**: Размер файла превышает максимально допустимый
- **Рекомендации**: Уменьшите размер файла или разделите его на несколько частей.

### 6001 - INVALID_FILE_TYPE

- **HTTP-код**: 415
- **Описание**: Недопустимый тип файла
- **Возможные причины**: Тип файла не входит в список поддерживаемых
- **Рекомендации**: Используйте файл поддерживаемого типа.

### 6002 - FILE_UPLOAD_FAILED

- **HTTP-код**: 500
- **Описание**: Ошибка загрузки файла
- **Возможные причины**: Проблемы при сохранении файла на сервере
- **Рекомендации**: Повторите попытку загрузки или обратитесь в службу поддержки.

### 6003 - FILE_NOT_FOUND

- **HTTP-код**: 404
- **Описание**: Файл не найден
- **Возможные причины**: Файл с указанным идентификатором не существует или был удален
- **Рекомендации**: Проверьте правильность идентификатора файла.

## 7. Ошибки интеграций (7000-7999)

### 7000 - EXTERNAL_SERVICE_ERROR

- **HTTP-код**: 502

- **Возможные причины**: Проблемы при взаимодействии с внешним сервисом
- **Рекомендации**: Повторите попытку позже или обратитесь в службу поддержки.

### 7001 - EXTERNAL_SERVICE_TIMEOUT

- **HTTP-код**: 504
- **Описание**: Таймаут внешнего сервиса
- **Возможные причины**: Внешний сервис не ответил в течение отведенного времени
- **Рекомендации**: Повторите попытку позже или обратитесь в службу поддержки.

### 7002 - EXTERNAL_SERVICE_UNAVAILABLE

- **HTTP-код**: 503
- **Описание**: Внешний сервис недоступен
- **Возможные причины**: Внешний сервис временно недоступен
- **Рекомендации**: Повторите попытку позже или обратитесь в службу поддержки.

## Обработка ошибок на стороне клиента

При разработке клиентских приложений рекомендуется:

1. **Обрабатывать коды ошибок**: Реализовать обработку всех возможных кодов ошибок, особенно часто встречающихся.

2. **Отображать понятные сообщения**: Преобразовывать технические сообщения об ошибках в понятные для пользователя.

3. **Реализовать автоматические повторы**: Для временных ошибок (например, 503, 504) реализовать механизм автоматических повторов с экспоненциальной задержкой.

4. **Логировать ошибки**: Сохранять информацию об ошибках для последующего анализа и отладки.

5. **Отправлять requestId в службу поддержки**: При обращении в службу поддержки указывать requestId из ответа с ошибкой.

## Заключение

Этот справочник кодов ошибок предоставляет полную информацию о возможных ошибках API системы Happyness. Использование стандартизированных кодов ошибок упрощает разработку клиентских приложений и обеспечивает единообразный подход к обработке ошибок во всей системе.
