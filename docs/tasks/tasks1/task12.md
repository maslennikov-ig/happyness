   - ✅ Сборка приложения
   - ✅ Запуск тестов

3. ✅ Настроить Docker сборку:

   - ✅ Создать Dockerfile для сборки приложения
   - ✅ Настроить GitHub Action для сборки и публикации Docker образа

4. ✅ Обновить документацию по CI/CD:
   - ✅ Описать настроенные пайплайны
   - ✅ Добавить инструкции по запуску и деплою

## Технические детали

### CI пайплайн

CI пайплайн запускается при каждом пуше в ветки `main` и `develop`, а также при создании пулл-реквестов в эти ветки. Он выполняет следующие задачи:

- Линтинг кода с помощью ESLint
- Проверка типов TypeScript
- Запуск тестов фронтенда и бэкенда

### CD пайплайн

CD пайплайн запускается при каждом пуше в ветку `main`. Он выполняет следующие задачи:

- Сборка приложения
- Запуск тестов
- Подготовка пакета для деплоя
- Деплой на продакшн сервер (имитация)

### Docker сборка

Пайплайн сборки Docker образа запускается при каждом пуше в ветку `main` и при создании тега с префиксом `v`. Он выполняет следующие задачи:

- Сборка Docker образа
- Публикация образа в GitHub Container Registry

## Связанные файлы
