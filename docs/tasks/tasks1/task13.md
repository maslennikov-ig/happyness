# Задача 1.3: Базовая настройка окружения разработки

## Правила работы с задачами
* **Отслеживание выполнения:** Выполненные задачи или подзадачи отмечаются как `[x]`.
* **Утверждение фаз:** Перед началом следующей крупной фазы разработки или модуля запрашивайте одобрение пользователя (руководителя проекта).
* **Задачи для пользователя-разработчика:** Если возникают задачи, требующие выполнения человеком-разработчиком, четко формулируйте задачу в чате и ожидайте подтверждения ее выполнения.
* **Отчет об изменениях:** Рядом с выполненной задачей указывайте список созданных или измененных файлов.
* **Планирование:** Не отмечайте будущие задачи как выполненные до получения явного запроса на их реализацию.
* **Структура и порядок:** Следуйте порядку задач, сгруппированных по спринтам. При генерации новых подзадач используйте единообразное именование и структуру.
* **Документация и ресурсы:** При необходимости добавляйте ссылки на релевантную документацию.
* **Блокировка задач:** Если задача заблокирована, четко указывайте причину и зависимости.
* **Проверка фаз:** Перед запросом на переход к следующей фазе убедитесь в полноте выполнения всех задач текущей фазы.
* **Комментарии и обоснования:** Используйте комментарии в коде для сложных участков и предоставляйте обоснования выбранных решений.

## Содержание задачи
- [ ] Настроить Docker-контейнеры для разработки (Сложность: Средняя)
  - **Вход:** Требования к окружению разработки, выбранный технологический стек
  - **Выход:** Docker Compose конфигурация с контейнерами для Next.js, NestJS и PostgreSQL
  
  ##### Подзадачи:
  - [ ] Создать базовый Dockerfile для Node.js с учетом версий из ТЗ (Сложность: Низкая)
    - **Вход:** Требования к Node.js версиям из ТЗ
    - **Выход:** Оптимизированный Dockerfile для Node.js

  - [ ] Настроить Docker Compose для локальной разработки (Сложность: Средняя)
    - **Вход:** Список необходимых сервисов (Next.js, NestJS, PostgreSQL, Redis)
    - **Выход:** docker-compose.yml с сервисами, готовыми для разработки

  - [ ] Настроить volumes для горячей перезагрузки кода (Сложность: Низкая)
    - **Вход:** Структура проекта, расположение исходного кода
    - **Выход:** Конфигурация volumes в docker-compose.yml для быстрой разработки

- [ ] Создать начальные конфигурационные файлы (.env.example, tsconfig.json, etc.) (Сложность: Средняя)
  - **Вход:** Требования к конфигурации приложения
  - **Выход:** Шаблоны конфигурационных файлов с документацией
  
  ##### Подзадачи:
  - [ ] Определить необходимые переменные окружения для различных сервисов (Сложность: Низкая)
    - **Вход:** Требования к компонентам системы из ТЗ
    - **Выход:** Список необходимых переменных окружения с описаниями

  - [ ] Создать шаблоны .env файлов для разных окружений (Сложность: Низкая)
    - **Вход:** Список переменных окружения
    - **Выход:** .env.example файлы для разных окружений (dev, test, prod)

  - [ ] Настроить конфигурационные файлы для TypeScript (Сложность: Средняя)
    - **Вход:** Требования к TypeScript из ТЗ, лучшие практики
    - **Выход:** Оптимизированные tsconfig.json для frontend и backend
