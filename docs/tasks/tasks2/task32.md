## Содержание задачи
- [ ] Разработать модуль для генерации текстового контента

* **Контекст и Цель:** Создать модуль для генерации различных типов текстового контента (описаний, статей, заголовков) с использованием выбранной LLM-модели, обеспечивая высокое качество, релевантность и настраиваемость выходных данных.

* **Ожидаемый Результат / Детализированные подзадачи:**
  - [ ] Разработать сервис для генерации текстового контента (Сложность: Высокая)
    - **Вход:** Интеграция с LLM-моделью из задачи 3.1, требования к генерации
    - **Выход:** Сервис с API для генерации различных типов контента
    
  - [ ] Создать систему промптов-шаблонов (Сложность: Средняя)
    - **Вход:** Примеры ожидаемого контента, требования к качеству
    - **Выход:** Библиотека шаблонов промптов для разных типов контента
    
  - [ ] Реализовать механизмы контроля качества (Сложность: Высокая)
    - **Вход:** Критерии качества из ТЗ, примеры хорошего/плохого контента
    - **Выход:** Система фильтрации и проверки сгенерированного контента
  
  - **Вход:** Интегрированная LLM-модель из задачи 3.1, требования к контенту
  - **Выход:** Готовый к использованию сервис генерации контента

* **Технологические Указания:**
  - Использовать технику few-shot learning для улучшения качества генерации
  - Применить prompt engineering для получения оптимальных результатов
  - Реализовать управление параметрами генерации (температура, top-p и т.д.)
  - Внедрить постобработку сгенерированного контента для улучшения качества

* **Нефункциональные Требования:**
  - Время генерации стандартного контента не должно превышать 5 секунд
  - Обеспечить высокую читаемость и естественность сгенерированных текстов
  - Контролировать токсичность и корректность генерируемого контента

* **Итеративность:** Начать с базовой генерации, итеративно улучшать качество путем настройки промптов и параметров.

* **Формат Вывода:** Готовый к использованию сервис для генерации текстового контента, включающий API для интеграции с другими компонентами системы. Должны быть реализованы эндпоинты для различных типов генерации (описания, статьи, заголовки) с настраиваемыми параметрами. Также должны быть предоставлены библиотека промптов-шаблонов, механизмы контроля качества и система постобработки. Результат должен включать документацию API, примеры использования и рекомендации по оптимизации генерации для различных сценариев.

* **Вопросы для Уточнения:**
  - Какие конкретные типы контента наиболее приоритетны?
  - Какие критерии качества наиболее важны для генерированных текстов?
  - Нужно ли поддерживать многоязычную генерацию?
  - Кто будет основными потребителями сгенерированного контента?

* **Фокус на Безопасности:**
  - Внедрить проверку на некорректный/токсичный контент
  - Обеспечить защиту от манипулирования системой через входные данные
  - Реализовать фильтрацию конфиденциальной информации в выходных данных

* **Документирование Кода:**
  - Подробно документировать API для интеграции с другими модулями
  - Создать руководство по созданию и оптимизации промптов-шаблонов

* **Генерация Тестов:**
  - Создать тесты для проверки качества генерации

* **Ожидаемый Результат / Детализированные подзадачи:**
  - [ ] Реализовать функционал классификации текста (Сложность: Высокая)
    - **Вход:** Интеграция с LLM-моделью, схема категорий для классификации
    - **Выход:** Сервис для классификации текста по заданным категориям
    
  - [ ] Разработать анализатор тональности и эмоций (Сложность: Средняя)
    - **Вход:** Требования к определению тональности и эмоций
    - **Выход:** Сервис для оценки эмоционального окраса текста
    
  - [ ] Создать экстрактор ключевых сущностей и тем (Сложность: Средняя)
    - **Вход:** Требования к определению важных сущностей и тем
    - **Выход:** Сервис для извлечения ключевой информации из текста
  
  - **Вход:** Интегрированная LLM-модель из задачи 3.1, требования к анализу
  - **Выход:** Комплексный сервис для анализа текста и классификации

* **Итеративность:** Начать с базовой классификации, последовательно добавлять функционал для анализа тональности и извлечения сущностей.

Должны быть реализованы основные аналитические функции: классификация по категориям, анализ тональности, извлечение ключевых сущностей и тем. Реализация должна быть гибкой, позволяющей адаптировать анализ под различные домены и задачи. Также должны быть предоставлены документация API, примеры использования и рекомендации по настройке для различных типов анализа.

  - Реализовать фильтрацию чувствительной информации в результатах анализа
