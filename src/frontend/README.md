# Frontend (Next.js)

Этот каталог содержит код фронтенда для платформы Happyness, который разработан с использованием следующего технологического стека:
- TypeScript 5.8.2+
- React 19.1.0+
- Next.js 15.3.2+
- Tailwind CSS 4.1.5+
- shadcn/ui (последние компоненты)
- React Hook Form 7.56.3+

## Структура каталогов

```
frontend/
├── app/               # App Router структура (Next.js)
│   ├── api/           # API роуты (Next.js backend)
│   ├── (auth)/        # Группа маршрутов аутентификации
│   ├── (dashboard)/   # Группа маршрутов, требующих аутентификации
│   ├── layout.tsx     # Корневой макет
│   └── page.tsx       # Главная страница
├── components/        # UI компоненты
│   ├── ui/            # shadcn/ui компоненты
│   └── forms/         # Компоненты форм
├── hooks/             # Кастомные React хуки
├── lib/               # Утилиты, хелперы, константы
├── services/          # Функции для взаимодействия с API
├── store/             # Глобальное состояние (Zustand, Jotai)
├── types/             # TypeScript типы и интерфейсы
└── styles/            # Глобальные стили (globals.css)
```

Базовая структура будет создана в рамках следующих задач спринта.
