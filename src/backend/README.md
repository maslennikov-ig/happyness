# Backend (NestJS)

Этот каталог содержит код бэкенда для платформы Happyness, который разработан с использованием следующего технологического стека:
- TypeScript 5.5.4+
- Node.js ^22.15.1
- NestJS 11.1.1+
- Prisma ^6.7.0 (ORM для работы с базой данных)
- Vitest ^3.2.0 (для тестирования)

## Установка и запуск

```bash
npm install          # Установка зависимостей
npm run start:dev    # Запуск в dev режиме
npm run test         # Запуск тестов
npm run test:watch   # Запуск тестов в watch режиме
npm run test:coverage # Запуск тестов с отчетом о покрытии
```

## Структура каталогов

```
backend/
├── src/                    # Исходный код
│   ├── main.ts             # Точка входа приложения
│   ├── app.module.ts       # Корневой модуль приложения
│   ├── core/               # Ядро системы
│   │   ├── auth/           # Базовая аутентификация и авторизация
│   │   ├── database/       # Базовая инфраструктура работы с БД
│   │   ├── config/         # Конфигурация ядра
│   │   └── common/         # Общие компоненты ядра
│   ├── modules/            # Функциональные модули
│   │   ├── users/          # Модуль управления пользователями
│   │   ├── companies/      # Модуль управления компаниями
│   │   ├── requests/       # Модуль управления запросами
│   │   ├── contractors/    # Модуль управления подрядчиками
│   │   ├── templates/      # Модуль управления шаблонами документов
│   │   ├── chat/           # Модуль для чата по запросам
│   │   ├── payments/       # Модуль управления платежами
│   │   └── notifications/  # Модуль управления уведомлениями
│   └── prisma/             # Prisma-сервис и интеграция
├── test/                   # Тесты
│   ├── e2e/                # E2E тесты
│   └── unit/               # Модульные тесты
└── prisma/                 # Prisma файлы (схема, миграции)
```

Данная структура обеспечивает модульность, масштабируемость и поддерживает принципы разделения ответственности (separation of concerns).

Базовая структура будет создана в рамках следующих задач спринта.
